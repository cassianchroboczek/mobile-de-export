# mobile.de Inserat kopieren (Chrome-Erweiterung)

Kopiert die wichtigsten Infos eines mobile.de-Inserats (Auto, Motorrad, Anhänger usw.) als reinen Text in die Zwischenablage. Fotos werden nicht übernommen.

## Installation
1. In Chrome `chrome://extensions` öffnen.
2. Oben rechts den **Entwicklermodus** einschalten.
3. **Entpackte Erweiterung laden** anklicken und den Ordner `src` auswählen.
4. Optional: Über das Puzzle-Symbol die Erweiterung an die Leiste anheften.

## Benutzung
Ein Inserat auf mobile.de öffnen und auf das Symbol klicken. Der Text wird sofort kopiert und im Fenster angezeigt. Dort kannst du ihn noch bearbeiten und mit dem Button erneut kopieren.

Übernommen werden: Titel, Preis, Inserat-ID, Link, technische Daten, Ausstattung, Beschreibung und Anbieter.
